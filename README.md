# Bandada

**Que la temporada no se termine.**

Presentación interactiva de la propuesta de startup del equipo para el Mundial de Estudiantes de Administración 2026 (CLAM, Mendoza).

Bandada encadena las cosechas de distintas provincias y países del MERCOSUR en un circuito anual, para que el trabajador golondrina pase de meses de changa y espera a un año completo de trabajo registrado.

- Página: https://nenocontreras.github.io/bandada/
- Archivo principal: `index.html` (HTML, CSS y JS sin dependencias, solo Google Fonts).

Documento de trabajo elaborado con apoyo de IA (Claude, Anthropic) para investigación y estructura; el equipo valida los supuestos y toma las decisiones.
